# Instagram Video Downloader Bot

This project is a Telegram bot that allows users to extract the source video link from an Instagram reel by simply providing the Instagram post URL. It uses Playwright to scrape Instagram video URLs and provides a caption generated based on the content of the video.

## Features

- **Instagram Video Scraping**: Extracts the source video URL from Instagram reels.
- **Caption Generation**: If the caption is missing, a random caption is generated for the video.
- **Telegram Bot**: Users can interact with the bot by sending Instagram post links to get the video source link and caption.
